# Mail Minter

**AI-powered email replies, right where you need them.**

Mail Minter writes a ready-to-send reply to any email in seconds. Use it directly inside Gmail with a one-click **🤖 AI Reply** button, or paste an email into the web app and choose the tone you want. Replies are generated by Google Gemini.

---

## Features

- **One-click replies in Gmail:** a Chrome extension adds an **AI Reply** button to Gmail's reply window. Click it and a draft reply appears in the compose box.
- **Web app:** paste any email, pick a tone, and copy the generated reply.
- **Tone control:** choose Formal, Casual, Friendly, Professional, or Default.
- **Light and dark mode** in the web app, and it remembers your choice.
- **No subject lines or filler:** you get just the reply body, ready to edit and send.

---

## How it works

Mail Minter is a single application. One server provides both the web app and the API that talks to Gemini. The Gmail extension uses the same API.

```
 Gmail (Chrome extension) ──┐
                            ├──►  Mail Minter (http://localhost:8080)  ──►  Google Gemini
 Web app (your browser) ────┘     web app + API in one server
```

1. You give Mail Minter the email you want to answer. The extension reads it from the open Gmail thread; in the web app you paste it in.
2. The server turns it into a prompt (including your chosen tone) and sends it to Google Gemini.
3. The generated reply comes back and is inserted into your Gmail draft or shown in the web app.

## Getting started

### Prerequisites

- A **Google Gemini API key**, free from [Google AI Studio](https://aistudio.google.com/app/apikey)
- **Java 17+**, or **Docker**
- **Google Chrome**, for the extension

You don't need to install Node.js; the build downloads it automatically.

### 1. Clone the repository

```bash
git clone https://github.com/karanupd12/Mail-minter.git
cd Mail-minter
```

### 2. Add your API key

Copy the example settings file and put your key in it:

```bash
cp .env.example .env
```

```env
GEMINI_API_KEY=your-api-key
```

`.env` is git-ignored, so your key never gets committed. By default Mail Minter uses the `gemini-2.0-flash` model. To use a different one, set `GEMINI_API_URL` in `.env`; the value must end with `?key=`.

### 3. Run Mail Minter

**Option A: Maven**

```bash
./mvnw spring-boot:run        # on Windows: mvnw.cmd spring-boot:run
```

**Option B: Docker**

```bash
docker build -t mail-minter .
docker run -p 8080:8080 --env-file .env mail-minter
```

Open **http://localhost:8080** to use the web app.

### 4. Install the Gmail extension (optional)

1. Open `chrome://extensions` in Chrome.
2. Turn on **Developer mode** (top-right).
3. Click **Load unpacked** and select the `extension/` folder.
4. Open [Gmail](https://mail.google.com), open an email, and click **Reply**.
5. Click **🤖 AI Reply** in the compose toolbar. Your draft appears in a few seconds.

> Mail Minter must be running on `localhost:8080` for the extension to work. The extension always uses a professional tone.

## API

The web app and the extension use a single endpoint, which you can also call directly:

```http
POST /api/email/generate
Content-Type: application/json

{
  "emailContent": "Hi, can we move tomorrow's meeting to 3pm?",
  "tone": "friendly"
}
```

The response is the generated reply as **plain text**. `tone` is optional.

## Troubleshooting

- **"Failed to generate reply" in Gmail:** make sure Mail Minter is running on port 8080.
- **Reply text says "Error processing response…":** check that `GEMINI_API_KEY` in `.env` is valid. If you set `GEMINI_API_URL`, check that it ends with `?key=`.
- **The AI Reply button doesn't appear:** reload the extension in `chrome://extensions`, then refresh Gmail. Gmail sometimes changes its page layout, which can stop the button from appearing.
